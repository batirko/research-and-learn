# Sources

The documents the guide rests on, as the owner gave them: notes, transcripts, emails, documents, saved copies of pages. **They are frozen.** Nobody edits a source after it lands here, even to fix an error. This README is the one file in the folder that changes: it lists the sources.

## What goes here

- Anything the owner gives at set-up or later: a file, a transcript of a conversation, notes from a meeting, an email, a handbook.
- A saved copy of a page about the case that might change or vanish, with the date it was saved.
- Not the guide's research. Candidate sources and their verdicts go in a topic's dossier in `research/`.

## Names and dates

Name each file `<name>-<YYYY-MM-DD>.<ext>`, such as `club-handbook-2026-09-12.pdf` or `mentor-call-2026-09-20.md`. The date is when the source was made, or when it was saved when that's unknown.

`<name>` is the source's name in a provenance tag: lowercase letters, digits and hyphens. A topic cites the handbook above as `[source: club-handbook p. 4]` and a private conversation as `[private: mentor-call 12:40]`. A place inside the source, such as a page or a time stamp, follows the name.

A transcript carries time stamps, so a tag can point at the exact line. Write a conversation without a transcript up as notes on the same day, and mark which parts are quotes.

## When a source is wrong or out of date

- **An error:** the worker who finds it says so in its handoff, with the evidence. The orchestrator adds the correction to the list of known errors in `orchestration/worker-pack.md` and to the decision log. The source stays as it is.
- **A newer version:** it goes in as a new file with its own date. The old one stays, and the list below says which one is current.
