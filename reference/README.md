# Reference

Earlier guides, or pages you want this guide to follow: a structure you liked, a tone, a depth. This folder is optional. Like the sources, what lands here is frozen.

The difference from `context/sources/`: a source tells the guide what is true about the case. A reference shows how a guide can look. Nothing here is evidence, and no topic cites it with a provenance tag.

## How workers use it

- Take the pattern, never the text. A topic doesn't copy a sentence from a reference.
- When a reference's facts are useful, check them like any other source, and cite the original.
- When a reference and a standard disagree, the standard wins.
